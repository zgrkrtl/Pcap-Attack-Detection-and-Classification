# PCAP Attack Detection and Classification

Machine learning-based network traffic analysis project for detecting and classifying cyber attacks from PCAP files.

## Overview

This repository demonstrates an end-to-end workflow for intrusion detection using packet capture (PCAP) data. The project extracts structured features from raw network traffic and trains machine learning models to identify malicious patterns such as scanning, brute force attempts, or denial-of-service behavior.

## Workflow

1. Parse PCAP files
2. Extract packet and flow-level features
3. Transform features into structured datasets
4. Train classification model
5. Evaluate performance using standard metrics
